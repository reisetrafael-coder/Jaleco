# Jaleco

App de estudos para técnico de enfermagem: check-in semanal com o conteúdo do curso, quizzes com IA, tutora, caderno de erros com revisão espaçada, anotações (com foto e ditado), agenda de provas com plano de revisão e lembretes diários.
